# Architecture Review Index

Numbered Architecture Review (AR) reports live in this directory. They retain
focused problem statements, options, decisions, consequences, and verification
evidence. This index is for discovery; implementation status remains owned by
`TODO.md` and the applicable phase `results.md`.

AR numbers are stable identifiers. Missing numbers are historical gaps and are
not renumbered. New reports use the next unused number and are linked from the
architecture decision log and relevant phase package.
