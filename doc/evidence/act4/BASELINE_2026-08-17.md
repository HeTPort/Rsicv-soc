## Reproduction

From the repository root in Windows PowerShell:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\sim\regress\run_act4_build.ps1 -Extension I
.\sim\regress\run_act4_build.ps1 -Extension M
.\sim\regress\run_regression.ps1 `
  -Manifest .\build\act4\tests.json `
  -Tag act4
```

The build logs, generated images, manifest, and per-test ModelSim transcripts
remain under ignored `build/act4/` and `sim/logs/regression/` directories.
`sim/regress/test_import_act4.py` independently checks mixed I/M classification
so a future import cannot silently label M cases as RV32I.

## Boundaries

- Privileged ACT4 groups are outside this selected baseline.
- The 256 KiB ACT4 simulation memory is not the synthesizable SoC's 64 KiB
  program/data memory profile.
- ACT4 does not replace directed CSR/trap, bus, timer, UART, GPIO, FreeRTOS, or
  physical FPGA verification.
