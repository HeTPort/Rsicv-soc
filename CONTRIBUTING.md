# Contributing

Bug reports, reproducible failing cases, documentation corrections, and design
discussion are welcome.

The project is operated under a noncommercial source-available license with
separate commercial licensing. To avoid unclear ownership and relicensing
rights, code, RTL, firmware, test, and substantial documentation contributions
are not accepted until the contributor and HeTPort have agreed to written
contribution terms. Opening an issue or sending a pull request does not by
itself grant HeTPort additional rights or guarantee acceptance.

Before preparing a substantial contribution, contact **Hetport@outlook.com**
with the intended scope and provenance. Do not submit confidential employer
material, copied code without compatible permission, generated material whose
terms are unclear, or third-party content without its exact license and origin.

Any accepted change must preserve third-party license boundaries, update the
living architecture/evidence documents when required, and pass the relevant
verification gates. See [`AGENTS.md`](AGENTS.md),
[`doc/RELEASE_CHECKLIST.md`](doc/RELEASE_CHECKLIST.md), and
[`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).
