# Idea Inbox

Files here are deliberately unfinished. They are committed so ideas can be
captured and reviewed across devices, but they are not project truth.

Use this template:

```markdown
---
status: inbox
created: YYYY-MM-DD
tags: [topic]
related_phase: none
data_classification: REVIEW_REQUIRED
---

# Short idea title

## Problem or opportunity

## Current idea

## Unknowns and risks

## Possible relationship

## Smallest next check
```

Replace `REVIEW_REQUIRED` before committing. Only `DATA-PUBLIC`, or
`DATA-INTERNAL` when this repository and its remotes are explicitly approved
for the intended readers, belongs here. If the idea may contain unpublished
competitive detail or its class is uncertain, keep it outside Git and follow
[`doc/INFORMATION_CLASSIFICATION_AND_HANDLING.md`](../../doc/INFORMATION_CLASSIFICATION_AND_HANDLING.md).

Do not turn a note into an implementation request merely because it exists.
