# Idea Inbox

Files here are deliberately unfinished. They are committed so ideas can be
captured and reviewed across devices, but they are not project truth.

Use this template:

```markdown
---
status: inbox
created: YYYY-MM-DD
tags: [topic]
related_phase: none
---

# Short idea title

## Problem or opportunity

## Current idea

## Unknowns and risks

## Possible relationship

## Smallest next check
```

Do not turn a note into an implementation request merely because it exists.
